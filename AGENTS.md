# Проект: Reels с ИИ-агентом

Рабочее пространство для монтажа вертикальных роликов. Две папки верхнего уровня:

| Папка | Что это |
|---|---|
| `config/` | настройки агента: скиллы, агенты, команды, правила, MCP. Пока пусто — наполняем по ходу недели |
| `Videomontage/` | монтаж роликов: `Rules/` — правила, стиль и стартер-кит, `Project/` — сами ролики |

## config/

| Подпапка | Что кладём |
|---|---|
| `skills/` | скиллы — каждый в своей подпапке с `SKILL.md` |
| `agents/` | субагенты — по одному `.md` с frontmatter (name, description, tools) |
| `commands/` | свои slash-команды — по одному `.md` |
| `rules/` | общие правила и договорённости — `.md`, подключаются отсюда через `@config/rules/<файл>.md` |
| `mcp/` | заметки по подключённым MCP-серверам (сам список серверов — `.mcp.json` в корне) |

## Videomontage/

Подробная навигация — `Videomontage/AGENTS.md`. Установка инструментов монтажа — `Videomontage/INSTALL.md`.

## Общие правила

- Пути к файлам и папкам — латиницей, без пробелов: ffmpeg спотыкается о кириллицу, особенно на Windows.
- `.env` не читать и не выводить — там ключи.
