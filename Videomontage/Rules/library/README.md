# Библиотека шаблонных элементов (library)

Файлы шаблона, которые встречаются в каждом ролике одинаково.

- `poloski.png` — декоративный элемент-плашка (см. упоминание «полоски»
  в старой версии `SKILL.md`, если решишь вернуть этот приём: растягивать
  на ширину кадра и держать поверх всех слоёв).
- `gradient-niz.png` — мягкий градиент/подложка снизу кадра.

Оба — абстрактная графика без стороннего копирайта (не стоковые фото и
не скриншоты), можно менять/перерисовывать под свой стиль. Добавляя
новые файлы — опиши их здесь же одной строкой на файл, чтобы имя и
назначение не приходилось разгадывать заново.
