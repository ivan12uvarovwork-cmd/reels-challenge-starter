# Microsoft Fluent Emoji — prepared stickers

The PNG files in `fluent-3d/` are resized/padded derivatives of Microsoft Fluent Emoji assets from:
https://github.com/microsoft/fluentui-emoji

They are prepared as transparent `220×220` canvases with the visible object contained within approximately `150×150` for the `video-montage` layout.
