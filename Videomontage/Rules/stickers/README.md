# Стикеры (stickers)

Только PNG с прозрачным фоном, используются как смысловые вставки рядом
с субтитрами (см. `Rules/skills/video-montage/SKILL.md`, раздел
«Смысловые стикеры у субтитров»). Холст `220×220`, объект около `150px`
по центру, отступ до края не меньше `28px`, контур `1px #111111` по
alpha-силуэту, не квадратная рамка.

## `fluent-3d/` — 14 готовых стикеров

Производные от [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji),
подготовленные под формат этого кита (холст 220×220). Лицензия — см.
`LICENSE-Fluent-Emoji.md` рядом, файл лицензии должен оставаться при
любом переносе/архивировании набора.

Набор: взрыв, галочка, глаза, искры, конфетти, лампочка, мешок денег,
монета, огонь, предупреждение, ракета, робот, рост графика, цель.

По правилам skill'а — не держи один и тот же стикер весь ролик, выбирай
`3–6` штук на ролик по смыслу конкретной реплики, не по остатку.
