# Указатель звуков (sfx)

Читай перед выбором звука к вставке/стикеру. Подбирай характер по
действию на экране, не по названию файла.

## В ките уже лежат (CC0, без ограничений)

Монеты/награда — [Kenney Casino Audio](https://www.kenney.nl/assets/casino-audio), лицензия CC0 (общественное достояние, можно использовать и редактировать без атрибуции):

- `coin-drop-single-01.wav`, `coin-drop-single-02.wav` — одна монета/награда появляется.
- `coins-clink-light.wav`, `coins-clink-sharp.wav` — короткое металлическое столкновение.
- `coins-handful.wav`, `coins-stack.wav` — несколько монет или накопленная награда.
- `coins-shower-short.wav` — короткий "дождь" монет.

## Что нужно докачать самому

Остальные категории (whoosh/pop/click/impact/riser/glitch и т.п.) в ките
намеренно не лежат — обычные библиотеки типа Pixabay Content License
разрешают использовать звук *внутри готового рендера*, но отдельно
явно запрещают раздавать сами файлы как самостоятельный набор (ровно
то, чем стал бы этот репозиторий, если бы их сюда положить). Возьми
свои — CC0/royalty-free источники вроде [Kenney](https://kenney.nl/assets),
[Pixabay Audio](https://pixabay.com/sound-effects/) (для использования в
своих рендерах — не для повторной раздачи файлов), [Freesound](https://freesound.org)
(смотри лицензию конкретного файла — не все там CC0).

| Тип действия | Характер звука |
|---|---|
| Движение / появление скрина | whoosh |
| Бейдж / стикер | мягкий pop / трансформация |
| UI-клик, переключение | click / ping |
| Сильный тезис, акцент | impact |
| Деньги, награда | coins (уже есть, см. выше) |

Добавляя свои файлы — впиши каждый в таблицу выше со своим типом и
источником/лицензией, чтобы выбор при монтаже был по смыслу, а не по
перебору файлов на слух, и чтобы происхождение файла не терялось.
