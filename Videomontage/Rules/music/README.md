# Музыка (music)

Фоновые треки в MP3 — по правилам skill'а `video-montage` музыка
обязательна с кадра 0 на весь ролик. Один трек на ролик, голос всегда
главный (дакинг громкости под речью).

Намеренно пусто в этом ките — фоновый трек почти всегда охраняется
авторским правом (в том числе royalty-free библиотеки обычно разрешают
использование в готовом видео, но не раздачу самого mp3-файла как
самостоятельного ассета). Положи сюда свой лицензионно чистый трек
(royalty-free библиотека, собственная запись) и сохрани файл
лицензии/подтверждения прав рядом.
