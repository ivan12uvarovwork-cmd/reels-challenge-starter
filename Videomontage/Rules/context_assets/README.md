# Общие ассеты (context_assets)

Картинки и видео, которые можно использовать во **всех** будущих роликах —
не привязанные к одной конкретной теме.

## `icons/fluent-3d/` — 14 готовых иконок

Тот же набор [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji),
что и в `Rules/stickers/fluent-3d/`, но отдельно подготовленный для
`BadgeStage` (значок сервиса/бренда, см. `Rules/РАСКЛАДКИ.md`) — крупнее
и без такого узкого поля вокруг объекта, как у стикеров. Лицензия — в
`icons/LICENSE-Fluent-Emoji.md`.

## Остальное — пусто, заполни своим

- Мемы, обобщённые скриншоты, реакции — что попадёт в кадр ещё не раз.
- Имя файла должно описывать содержимое: `скрин статистики.jpg`,
  `мем кот.jpg`, а не `IMG_1234.jpg`.
- Не копируй всю библиотеку в каждый проект — выбранные файлы копируются
  в `Project/<название>/remotion-edit/public/media/` по мере надобности,
  оригиналы остаются здесь.
- Сохраняй файлы лицензий рядом с библиотекой, если используешь чужие
  ассеты (стоки, готовые наборы иконок) — как это сделано для fluent-3d.
