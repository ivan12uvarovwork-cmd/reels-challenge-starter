# Монтаж вертикальных роликов

Ролики 1080×1920 на Remotion.

## Структура

- `INSTALL.md` — что поставить на компьютер один раз (Node 22, ffmpeg, faster-whisper) и как проверить.
- `Rules/` — источник правил и кода, своего `package.json` нет, сама не запускается.
  - `src/` — компоненты Remotion; цвет и шрифт меняются в `src/style.ts`.
  - `skills/video-montage/SKILL.md` — процесс монтажа по фазам.
  - `РАСКЛАДКИ.md` — раскладки вставок, хук, субтитры, шрифт.
  - `ПРЕСЕТЫ_стилей.md` — пять готовых стилей.
  - `ГРАБЛИ.md` — типовые проблемы без понятной ошибки.
  - `context_assets/`, `library/`, `stickers/`, `music/`, `sfx/` — общая медиатека.
- `Project/` — ролики.
  - `example/` — рабочий пример, только для проверки установки, не править.
  - `<название>/remotion-edit/` — проект конкретного ролика, исходники в `public/media/`.

## Правила

- Монтаж — строго по `Rules/skills/video-montage/SKILL.md`.
- Новый ролик — новая папка в `Project/`, `Rules/` копируется в неё, а не правится под один ролик.
