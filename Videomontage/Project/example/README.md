# Пример проекта

Рабочий, готовый к запуску пример — не только текст правил, а код,
который реально собирается и рендерится.

```bash
cd remotion-edit
npm install
npm run dev     # remotion studio — предпросмотр композиции Example
npm run still   # один кадр в out/check.png — быстрая проверка шрифта/субтитров
npm run render  # видео в out/example.mp4
```

`remotion-edit/src/` — точная копия `Rules/src/` на момент публикации кита:
никаких внешних медиафайлов, композиция `Example` использует только
субтитры и шрифты, поэтому рендерится сразу после `npm install`, без
своего видео с говорящей головой.

Когда будешь собирать свой реальный ролик, добавь в этот же
`remotion-edit/` новую композицию в `Root.tsx`, положи исходник и b-roll
в `public/media/` и следуй `Rules/skills/video-montage/SKILL.md`.

- [`words-example.json`](words-example.json) — как выглядит результат
  пословной транскрибации (Фаза 1 skill'а) на выдуманном тексте: формат
  `{word, start, end}`, без реального аудио.
- [`plan-example.md`](plan-example.md) — как выглядит одна сплошная
  таблица монтажного плана (Фаза 3 skill'а) на условном примере, с
  вымышленными названиями файлов вместо реального b-roll.
